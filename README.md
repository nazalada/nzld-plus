# NZLD+

Плагин к CapCut на macOS. Добавляет вкладку **NZLD+** в левую верхнюю панель и то,
чего в маковском CapCut нет:

- **3D-камера и параллакс** — слои разносятся по глубине, камера летает вокруг сцены:
  наезд, облёт, ролл. Движение пишется ключами в проект, экспорт его отыгрывает.
- **Перспектива (corner-pin)** — настоящая четырёхугольная гомография на слое. Движок
  её умеет, но в маковском интерфейсе её нет. Типовая задача — вклеить видео в экранчик
  внутри другого видео.
- **Трекинг уровня After Effects** — точечный на CoTracker3 и планарный (плоскость
  целиком, вместе с поворотом и перспективой). Результат применяется живьём, без
  переоткрытия проекта.
- **Глубина резкости** — размытие по расстоянию до плоскости фокуса.

Интерфейс **только на русском**. Это решение, а не недоделка.

## Требования

- macOS на Apple Silicon. Дилиб собран **только под arm64**: хуки — ручные детуры под
  инструкции этой архитектуры.
- **CapCut 9.1.0 или 9.2.0.** Проверено на обеих. Функции движка резолвятся по именам
  символов и обновления обычно переживают, но смещения полей — нет, поэтому на незнакомой
  версии лаунчер откажется запускаться, а не сломается молча.
- **Python 3.12 или новее.** Тот `python3`, что идёт с macOS, — 3.9.6, его не хватает.
  Если подходящего нет, установщик скажет об этом прямо и подскажет, где взять.
- Дисковое место: ≈950 МБ под Python-окружение (почти всё — torch), качается ≈207 МБ.

Xcode не нужен: собранный и подписанный дилиб лежит в репозитории.

## Установка

```sh
git clone <репозиторий> nzld
cd nzld
./install.sh
```

Установщик разложит панель, поставит дилиб и создаст Python-окружение. Запускать его
повторно безопасно — он ничего не ломает.

Дальше — **двойной клик по `CapCut Probe.command`**. Он поднимает бэкенд, проверяет, что
тот отвечает, и только потом запускает CapCut с плагином.

Запускать CapCut надо именно так: обычный запуск даёт CapCut вообще без плагина.

Первый трекинг тянет модель CoTracker3 с `torch.hub` — нужен интернет один раз.

> Если качал **ZIP** вместо `git clone`, macOS пометит файлы как «скачанные из
> интернета», и Finder не даст запустить `CapCut Probe.command` двойным кликом.
> Установщик снимает эту метку сам и пишет об этом строкой в выводе.

## Права macOS

Плагин просит **один** доступ: «Универсальный доступ» (Accessibility) для **Терминала** —
того приложения, из которого запущен `CapCut Probe.command`.

Он нужен, чтобы закрывать и открывать проект: CapCut никогда не перечитывает файл проекта,
пока проект открыт, поэтому часть работы плагин делает по закрытому, а потом открывает его
обратно — кликом по плитке на главной, как это сделал бы человек.

macOS спросит разрешение сама при первой такой операции. Если случайно отказал —
«Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ»,
включить Терминал. Плагин объяснит это же строкой в панели, если упрётся.

**Запись экрана (Screen Recording) не нужна.** Её просит только `check_camera.py` —
инструмент разработчика, не часть работы пользователя.

## Из чего собрано

Три части, разговаривающие через файлы и HTTP:

| Часть | Что это | Где живёт |
|---|---|---|
| `ve_hook.cpp` → `ve_hook.dylib` | инжектится в процесс CapCut, ставит хуки, рисует панель и оверлеи | `User Data/` |
| `app.py` и соседи | бэкенд на 127.0.0.1:8756, голая stdlib: трекинг, математика камеры, запись проекта | репозиторий |
| `qml/*.qml` | сама панель, на родных компонентах CapCut | `User Data/` |

Панель лежит файлами, а не внутри дилиба — морда правится без пересборки бинарника.
Правишь её живьём в `~/Movies/CapCut/User Data/`, перед коммитом забираешь обратно
командой `./install.sh --collect`.

## Сборка — только разработчику

Пользователю она не нужна: дилиб едет в репозитории собранным.

`./build.sh` (нужен `xcode-select --install`). Два правила, которые нельзя нарушать:

- **Без `-O2`.** Хуки — ручные детуры с украденными инструкциями; смена уровня
  оптимизации меняет то, что компилятор делает с кодом трамплина.
- **В конце `mv`, а не `cp`.** Запись поверх уже отображённой в память библиотеки бьёт
  page hashes загруженного кода; `mv` подменяет файл целиком.

Собрал и проверил живьём — `./install.sh --collect`. Он заберёт в репозиторий морду,
дилиб и отпечаток `ve_hook.cpp`, из которого тот собран. Установщик этот отпечаток
сверяет и предупреждает, если бинарь собран не из лежащего рядом исходника.
